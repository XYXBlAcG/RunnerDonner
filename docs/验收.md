# 手动验收

界面与手机显示由用户亲自验收。以下步骤尚未由自动化执行。

## 准备

打开完整应用，选择 iOS 27 USB 直连，连接并解锁手机，刷新、选择设备、连接。
请勿让其他定位模拟软件同时控制同一手机。定位模拟成功不代表运动 App 接受记录。

## GPX 起点固定定位

1. 选择一个 GPX，点击“GPX 起点定位”。
2. 在手机地图确认位置处于该轨迹起点。
3. 等待一段时间，确认位置保持不变，没有出现路线进度。
4. 点击“恢复真实定位”，在手机地图确认。

## 地图选点

1. 无需选择 GPX，点击“地图选点”。
2. 可搜索地点并选择结果；拖动、缩放后单击目标位置。
3. 确认标记正确，点击“定位到此处”。在手机地图确认位置保持不变。
4. 再次打开地图，确认能够取消，且取消不会改变手机位置。
5. 点击“恢复真实定位”。

## 地图坐标与探索地图

1. 分别打开“地图选点”和“编辑 GPX…”，确认均为标准矢量地图，没有卫星影像。
2. 打开此前在手机上定位正确的南京大学运动场 GPX，确认折线和点位与运动场重合，不再显示在北京西路北侧。
3. 不编辑路线，另存并重新打开；检查起终点、距离和位置未发生变化。
4. 搜索“南京大学鼓楼校区苏浙运动场”，检查搜索结果、路线、点位和底图一致。
5. 选取运动场上的位置并固定定位，在手机地图确认位置与面板选点一致。
6. 在编辑器内小幅拖动一个点、添加一个点，保存并重开；检查只有预期改动，没有整条路线偏移，再验证撤销与重做。

地图显示、搜索供应方及手机位置需以当前环境验收；数值转换测试不代表底图精度。若仍有偏移，请记录地图供应方、地标、方向和大致距离，并提供截图。

## GPX 可视化编辑

1. 选择现有 GPX，点击“编辑 GPX…”，检查路线、起终点、点数和公里数。
2. 选择一个点并拖动，检查折线和距离更新；移动闭合路线起点，检查首尾仍重合。
3. 切到“添加点”，点击空白处，在选中点后插入；切回选择工具，选点并删除。
4. 逐次撤销、重做，检查每次操作只对应一次编辑。放大地图，检查密集点可以选择和拖动。
5. 点击“显示全程”，再搜索地点；检查平移缩放与搜索不会修改路线。
6. 取消编辑，选择放弃，检查主面板原路线未改变；重新编辑并“另存并载入…”，确认主面板使用新文件，原文件保留。
7. 重新打开保存的文件，检查点数、公里数和路线与保存前一致。
8. 点击“新建路线…”，搜索地点并画出至少两个点，另存载入。
9. 路线运行和暂停时，检查新建与编辑入口均不可用。

## GPX 随机扰动

1. 编辑现有 GPX，保持默认幅度，点击“随机扰动”，放大地图检查橙色预览。
2. 连续点击“重新随机”，检查每次结果不同，未应用前不能保存。
3. 调节幅度，检查预览更新；取消扰动，检查回到编辑草稿。
4. 再次生成并应用，检查可撤销、重做，闭合路线仍首尾重合，距离为当前路线的实际计算结果。
5. 另存后重开，检查应用后的坐标被保留。扰动不提供道路或运动场边界约束，请自行检查路线位置。

## 暂停、调速与继续

1. 选择 GPX，输入 `6:00`，关闭波动，点击“开始”。
2. 运行至明显离开起点后点击“暂停”，记录进度与手机位置。
3. 等待，确认位置与进度保持不变，配速和波动控件可编辑。
4. 将配速改为 `5:00`，开启波动并设为 `±20`，点击“继续”。
5. 确认从暂停位置接着前进，没有返回起点，累计进度没有清零。
6. 重复暂停和继续；一次不改参数、一次关闭波动，检查结果。
7. 暂停后输入无效配速，确认无法继续且暂停进度保留。
8. 暂停后点击“重新开始”，取消确认时不应改变进度；确认后才回到 GPX 起点并清零。
9. 最后点击“恢复真实定位”。

## 反馈

若结果不符合预期，请提供失败步骤、界面状态文字、手机地图观察结果、iOS 具体版本，以及是否发生锁屏、睡眠或拔线。请勿提供配对文件或认证信息。
